01Professional work

Nucleus Learning / Vue.js

Making large question banks easier to use

Assessment authors could run into timeouts when opening large banks. I moved question loading to on-demand requests with server-side pagination and kept selections intact as authors searched, filtered and moved between pages.

Implementation notes

The change reused the existing assessment and template controls. The selector discarded stale responses after a filter change, supported retrying a failed request and preserved safeguards for mandatory questions.

I also worked on the assessment enrolment view, where the reviewer can see time spent alongside the score and switch between attempts without the attempt list changing width.
